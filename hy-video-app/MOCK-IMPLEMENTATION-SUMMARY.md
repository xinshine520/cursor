## 🚀 Mock API 功能

### 素材 API
```typescript
// 获取素材列表
getMockOfficialMaterials(page, pageSize)
getMockPersonalMaterials(page, pageSize)
getMockGeneratedMaterials(page, pageSize)

// 搜索和交互
searchMockMaterials(keyword)
downloadMockMaterial(id)
likeMockMaterial(id)
```

### 资产 API
```typescript
// 获取资产列表
getMockCreationAssets(page, pageSize)
getMockBrandAssets(page, pageSize)
getMockWorkAssets(page, pageSize)

// 详情和交互
getMockAssetDetail(id)
searchMockAssets(keyword)
likeMockAsset(id)
shareMockAsset(id)
deleteMockAsset(id)
publishMockAsset(id)
```

## 🎯 Mock 特性

1. **网络延迟模拟**：300-800ms
2. **分页支持**：page 和 pageSize 参数
3. **数据验证**：用户名/密码/状态验证
4. **错误处理**：模拟各种错误场景
5. **状态管理**：本地存储持久化
6. **交互反馈**：点赞、下载、分享计数
