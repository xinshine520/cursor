**验收标准**：
- [ ] 数据库连接成功
- [ ] JPA 可正常工作

**application.yml 参考配置**：
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/hyai_db
    username: postgres
    password: your_password
    driver-class-name: org.postgresql.Driver
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
```
