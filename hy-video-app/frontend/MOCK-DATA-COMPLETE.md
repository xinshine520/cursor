## 🎯 功能特性

### Mock API 特性
1. **模拟网络延迟**：300ms - 800ms
2. **分页支持**：支持 page 和 pageSize 参数
3. **搜索功能**：支持关键词搜索标题和标签
4. **交互功能**：
   - ✅ 点赞（自动增加计数）
   - ✅ 下载（自动增加计数）
   - ✅ 分享（生成分享链接）
   - ✅ 发布/删除资产

### 数据格式化
- **文件大小**：formatFileSize() - 自动转换为 B/KB/MB/GB
- **时长**：formatDuration() - 格式化为 mm:ss 或 hh:mm:ss
- **数字**：formatNumber() - 超过万自动显示为 x.xw
