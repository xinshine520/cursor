# 测试用例文档

## 测试环境

- 前端：http://localhost:5173
- 后端：http://localhost:8080/api/v1
- 数据库：PostgreSQL (localhost:5432)
- Redis：localhost:6379

## 1. 用户认证测试

### 1.1 用户注册
- **测试步骤**：
  1. 访问注册页面
  2. 输入用户名、密码、邮箱
  3. 点击注册按钮
- **预期结果**：注册成功，返回用户信息
- **测试数据**：
  - 用户名：testuser
  - 密码：123456
  - 邮箱：test@example.com

### 1.2 用户登录
- **测试步骤**：
  1. 访问登录页面
  2. 输入用户名和密码
  3. 点击登录按钮
- **预期结果**：登录成功，返回 Token 和用户信息
- **测试数据**：
  - 用户名：testuser
  - 密码：123456

### 1.3 Token 验证
- **测试步骤**：
  1. 登录获取 Token
  2. 使用 Token 访问需要认证的接口
- **预期结果**：接口正常返回数据

### 1.4 Token 过期处理
- **测试步骤**：
  1. 使用过期的 Token 访问接口
- **预期结果**：自动跳转到登录页面

## 2. 素材管理测试

### 2.1 获取素材列表
- **接口**：`GET /materials`
- **测试步骤**：
  1. 登录获取 Token
  2. 调用素材列表接口
  3. 测试分页参数
  4. 测试分类筛选
- **预期结果**：返回素材列表，支持分页和筛选

### 2.2 创建素材
- **接口**：`POST /materials`
- **测试步骤**：
  1. 登录获取 Token
  2. 调用创建素材接口
  3. 传入素材信息
- **预期结果**：创建成功，返回素材信息
- **测试数据**：
  ```json
  {
    "title": "测试素材",
    "type": "video",
    "category": "personal",
    "url": "https://example.com/video.mp4"
  }
  ```

### 2.3 更新素材
- **接口**：`PUT /materials/{id}`
- **测试步骤**：
  1. 创建素材获取 ID
  2. 调用更新接口
  3. 修改素材信息
- **预期结果**：更新成功

### 2.4 删除素材
- **接口**：`DELETE /materials/{id}`
- **测试步骤**：
  1. 创建素材获取 ID
  2. 调用删除接口
  3. 再次查询该素材
- **预期结果**：删除成功，查询不到该素材
