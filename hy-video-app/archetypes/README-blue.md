# 华玥AI - 蓝色主题原型说明

## 简介

`index-blue.html` 是一个使用蓝色主题和 Font Awesome 图标库的纯 HTML+CSS 前端原型文件。

## 特点

- ✅ **专业图标**：使用 Font Awesome 6.4.0 图标库
- ✅ **蓝色主题**：现代化的蓝色渐变配色方案
- ✅ **流畅动画**：丰富的交互动画和悬停效果
- ✅ **响应式设计**：完美适配移动端显示
- ✅ **无依赖**：除了 Font Awesome CDN，无需其他依赖

## 使用方法

1. 直接在浏览器中打开 `index-blue.html` 文件
2. 需要网络连接以加载 Font Awesome 图标库（CDN）
3. 点击底部导航栏切换不同页面
4. 在素材页和资产页中可以切换不同的标签/分类

## 功能清单

### ✅ 底部导航栏（4个）
- 首页
- 素材
- 资产
- 我的

### ✅ 素材页（3个标签）
- **官方**：系统预设的高质量模板与素材
- **个人**：用户上传或收藏的私有素材
- **生成**：通过 AI 能力生成的初步素材成品

### ✅ 资产页（3个分类）
- **智能创作**：正在进行中或待优化的 AI 项目（带进度条）
- **品牌视频**：高价值的商业化视频资产
- **作品**：已完成并导出的个人成品展示

### ✅ 我的页面

**AI 工具箱**（13个工具）：
- 帐号对标、抖音爆款、IP 精灵
- 文案提取、选题生成、文案生成、标题生成、文案改写
- 朋友圈文案、小红书文案
- 视频创作、形象训练、声音训练

**账户管理**（7个选项）：
- 基本信息、我的资产、我的数字人、我的声音
- 授权视频、卡密兑换、帐号设置
